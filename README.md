# Arthur Siew — Flask Portfolio Website 🌐

This is my personal portfolio website built with Python and Flask. It showcases my experience, projects, skills, and blog posts. It also includes a fun "Scratch Page" where users can leave comments — all backed by a MySQL database.

## 🚀 Live Demo

🌐 [View Website on PythonAnywhere] (http://asiewm01.pythonanywhere.com)
_(Will update after deployment)_

## 🛠 Tech Stack

- **Frontend**: HTML, Bootstrap 4, Jinja2
- **Backend**: Python, Flask
- **Database**: MySQL (with SQLAlchemy ORM)
- **Version Control**: Git + GitHub
- **Deployment**: PythonAnywhere

## 📁 Features

- About Me, Resume, Skills, Portfolio, Blog, Contact
- Modular Flask Blueprints
- Scratch Page with comment form (MySQL + SQLAlchemy)
- Fully responsive with Bootstrap
- Hosted online (PythonAnywhere)

## ⚙️ Installation (For Developers)

```bash
git clone https://github.com/asiewm01/arthur_siew_portfolio.git
cd arthur_siew_portfolio
python -m venv .venv
source .venv/bin/activate  # or .venv\Scripts\activate on Windows
pip install -r requirements.txt
flask run
